Промпт-инжиниринг: от нуля до продвинутого

###Уровни

###1 - четкие инструкции
Плохо: «Напиши что-нибудь о собаках». → Хорошо: «Напиши абзац из 150 слов для сайта ветеринара, успокаивающий владельцев об анестезии».

###2.Несколько выстрелов
Приведите 2-3 примера ввода/вывода до вашего реального ввода — модель имитирует шаблон.

###3. Персона + контекст
«Вы старший SRE, рассматривающий вскрытие...» стиль кадров, глубина и словарный запас.

###4 Структура и разграничители
Используйте XML-теги (`<context>…</context>`, `<task>…</task>`) — модели надежно их разбирают.

###5 Цепь мысли
«Думай шаг за шагом» — или лучше: прямо попросите сначала спланировать, а затем ответить.

###6.Ограниченный выход
Укажите формат: схема JSON, таблица разметки, точная длина. Проверяйте программно.

###7 Самокритика
«Проект → критика вашего проекта → производство финала». Один дополнительный шаг, большой качественный прыжок.

###8 Использование инструментов и RAG
Дайте модели функции поиска + вместо того, чтобы надеяться, что она знает — самый большой рычаг надежности.

##  ️ Режимы отказа
** Нечеткие цели** расплывчатый результат
** Противоречивые инструкции** → модель выбирает одну молча
**В поисках достоверности** по неопределенным темам → галлюцинации; предпочитайте говорить, когда вы не знаете
**Быстрая инъекция** — никогда не вводите ненадежный пользовательский текст в системные подсказки

##  patterns Продвинутые шаблоны

### Цепочка проверки (CoVe)
1.Проект ответа → 2. Сформулируйте вопросы проверки → 3. Ответьте самостоятельно 4. Пересмотри. Резко режет галлюцинации.

### Самосогласованность
Образец того же CoT подскажет 5-10× при температуре 0,7, большинство-голосуйте ответ. +10-20% по аргументирующим ориентирам.

### Реакция (Разум + Акт)
Interleave `Thought:` / `Action:` / `Observation:` — основа агентов, использующих инструменты.

###Скелет мысли
Сначала сгенерируйте схему, затем ответьте на каждую точку * параллельно *. Быстрее + структурированнее.

##  ️ Быстрый впрыск

Пользовательский ввод никогда не является доверенным контекстом — разграничьте + проинструктируйте модель
Инструменты / контент RAG могут содержать инструкции: относиться к извлеченному тексту как к ненадежному
- Углубленная оборона: валидация выхода > быстрое закаливание
